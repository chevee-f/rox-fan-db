Cookies & Local Storage Policy

This policy explains how the Introboys Fan Database Site (“Site”) uses cookies and similar browser storage technologies.

1. Do We Use Cookies?

The core Site tools primarily use localStorage and sessionStorage rather than HTTP cookies. If analytics is enabled on the live server (Umami, Cloudflare Web Analytics, or Plausible), a small analytics script may run to count page views. These services are typically cookieless or use minimal first-party storage.

2. Local Storage We Use

Key / areaPurposeDuration
ro_app_settings Theme, sound profile, volume, notification preference Until cleared
ro_dashboard_columns, ro_active_trackers Spawn tracker boards and timer state Until cleared
ro_guest_sessions, guest_sessions Remember shared groups you joined as a guest Until cleared
share_nickname (sessionStorage) Your chosen nickname for shared groups this tab session Tab session
Theme preference (via theme.js) Selected color theme Until cleared

3. Why We Store This Data

Local storage lets the Site remember your layout and preferences without an account. Shared spawn sync may additionally store group membership on a server you connect to.

4. Your Controls

  • Clear site data in your browser settings (Chrome: Settings → Privacy → Delete browsing data → Cached images and files / Site settings).
  • Use the Site’s settings modal or “hard wipe” option on the timers page to reset local tracker data.
  • Block storage in browser settings — note that tools may not function correctly.

5. Updates

We may update this policy when storage practices change. Check the date above.
